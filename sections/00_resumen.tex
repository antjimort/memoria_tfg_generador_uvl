\chapter*{Resumen}
\markboth{Resumen}{}
\addcontentsline{toc}{chapter}{Resumen}

Este Trabajo de Fin de Grado aborda el desarrollo y la integración de un
generador configurable de modelos de características en UVLHub, una plataforma
orientada a la gestión y manipulación de modelos escritos en Universal
Variability Language (UVL). El trabajo responde a la necesidad de disponer de
modelos UVL expresivos y configurables con los que evaluar herramientas de
análisis de variabilidad software, incluidos modelos con atributos y
restricciones complejas. Para ello, se ha desarrollado un componente
generador independiente siguiendo el sistema de extensiones de Flamapy. Este
componente separa la configuración del generador de las operaciones que
construyen los modelos. Además, se ha adaptado el módulo de UVLHub para
delegar en él la lógica de generación, lo que facilita su reutilización y
mantenimiento. La solución se ha implementado con Python y Flask. El entorno
de desarrollo local se ha definido mediante Docker Compose y se ha desplegado
una instancia de revisión en Render. También se ha adaptado la infraestructura
de pruebas del módulo. La opción de generación con comprobación SAT limita
la generación al nivel booleano y verifica la satisfacibilidad de los modelos
generados. La solución se ha comprobado mediante 264 pruebas automatizadas superadas, incluidas pruebas de interfaz con pytest y Selenium. La principal aportación es una base modular para generar
modelos UVL destinada a la evaluación y el desarrollo de herramientas de
análisis de variabilidad.

\vspace{1.5em}
\noindent\textbf{Palabras clave:} SPL, UVL, UVLHub, Flamapy, modelos de
características, generación automática de modelos, Python, Docker, pruebas
automatizadas.

\chapter*{Abstract}
\markboth{Abstract}{}
\addcontentsline{toc}{chapter}{Abstract}

This Final Degree Project addresses the development and integration of a
configurable feature model generator into UVLHub, a platform for managing and
manipulating models written in the Universal Variability Language (UVL). The
work responds to the need for expressive and configurable UVL models with
which to evaluate software variability analysis tools, including models with
attributes and complex constraints. To this end, an independent generator
component was developed following Flamapy's plugin architecture. The component
separates the generator configuration from the operations that build the
models. The UVLHub generator module was also adapted to delegate its generation
logic to this component, facilitating reuse and maintenance. The solution was
implemented with Python and Flask. The local development environment was
defined with Docker Compose, and a review instance was deployed on Render. The
module's testing infrastructure was also adapted. The SAT-checked generation
option limits generation to the Boolean level and checks the satisfiability of
the generated models. The solution was verified by 264 passing automated tests, including interface tests using pytest and Selenium. The main contribution is a modular foundation for
generating UVL models to support the evaluation and development of variability
analysis tools.

\vspace{1.5em}
\noindent\textbf{Keywords:} SPL, UVL, UVLHub, Flamapy, feature models,
automatic model generation, Python, Docker, automated testing.
